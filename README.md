# Nano Banana Drawing Board

Одна версия приложения: React + Vite + Express.

## 1. Настройка ключа

Файл `.env` должен лежать **в этой папке, рядом с `server.ts`**:

```env
POLZA_API_KEY=pza_ваш_ключ
PORT=3000
```

Не называй его `.env.txt`.

## 2. Установка

```powershell
npm.cmd install
```

## 3. Запуск

```powershell
npm.cmd run dev
```

Либо дважды кликни `start.bat`.

В консоли обязательно должно быть:

`Polza: configured (key: pza_…1234)`

и

`.env: C:\...\nanobanana-v8\\.env (найден)`

## API

Polza endpoint: `https://polza.ai/api/v1/media`

Model: `google/gemini-nano-banana-2.1` (можно переопределить `POLZA_MODEL` в `.env`)

## Защита доступа
Добавь в `.env` общий пароль для доступа к редактору и API генерации:

```env
APP_PASSWORD=замени-на-длинный-уникальный-пароль
```

Без `APP_PASSWORD` генерация закрыта. После установки пароля перезапусти сервер. Сессия хранится в HttpOnly cookie и действует 12 часов.

Сохранённые холсты хранятся локально в браузере на этом устройстве; для резервной копии используйте также «Сохранить PNG».

## Защита монет
Дополнительные необязательные настройки `.env`:

```env
GENERATION_COOLDOWN_MS=3000   # пауза между генерациями одного пользователя
GENERATION_LIMIT=0            # общий лимит генераций за запуск сервера (0 = без лимита)
COOKIE_SECURE=true            # ставить, если сайт открыт по https
```

- пароль сравнивается за постоянное время, после 5 неверных попыток вход блокируется на 5 минут;
- сессии истекают на сервере через 12 часов;
- одновременно у пользователя может идти только одна генерация;
- на мероприятии рекомендуется поставить `GENERATION_LIMIT` (например, 100).

## Холст и сохранения
- Внутреннее разрешение холста фиксировано (1600×1000), поэтому при изменении окна и масштаба рисунок не «мылится».
- Сохранённые холсты лежат в IndexedDB браузера (кнопка «Мои холсты»); есть скачивание PNG и загрузка из файла.
- Горячие клавиши: Ctrl+Z — назад, Ctrl+Y / Ctrl+Shift+Z — вперёд.
