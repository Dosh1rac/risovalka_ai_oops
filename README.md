# Nano Banana Drawing Board

## Установка на Windows

1. Установи Node.js LTS (если ещё не установлен): https://nodejs.org/
2. Распакуй архив в обычную папку, например `C:\\nanobanana-drawing-board`.
3. Скопируй `.env.example` и назови копию `.env`.
4. Открой `.env` и укажи **новый** ключ Polza в `POLZA_API_KEY`, а также придумай пароль приложения в `APP_PASSWORD`.
5. Открой папку проекта в терминале PowerShell и выполни:

   ```powershell
   npm install
   npm run dev
   ```

6. Открой http://localhost:3000

Можно запустить через `start.bat` после выполнения `npm install`.

## Если генерация падает на загрузке рисунка

Сервер повторяет временные сетевые сбои Polza Storage до трёх раз и печатает причину ошибки в консоль. Если все попытки не удались, проверь доступ к `https://polza.ai/api/v1/storage/upload`, соединение/DNS и состояние ключа в личном кабинете Polza. Повторные попытки не могут исправить недоступность самого сервиса или неверный API-ключ.

## Безопасность

Не отправляй файл `.env` другим людям и не загружай его в Git. Если API-ключ уже попадал в публичный архив/чат, отзови его и создай новый.
